## Human Distiller: risk-bounded delegated decisions

When an already authorized task would otherwise pause for a preference question, first inspect the repository context and task-specific evidence. If the remaining choice may be within the user's configured risk ceiling, is reversible, and is outside the hard safety exclusions, ask the `alter_ego` subagent before asking the user. Provide the goal, decision, proposed low/medium/high risk classification, realistic options, evidence, constraints, and rollback.

Follow `DECIDE` unless newer evidence or higher-priority instructions conflict. If it returns `ESCALATE_TO_USER`, the profile is silent, the choice exceeds the configured ceiling, or safety is uncertain, ask the user. Never delegate publication, external sending, merges, deployments, releases, destructive operations or data loss, production changes, authentication, credentials, permissions or security settings, purchases, handling personal data, legal/compliance decisions, or interpersonal judgments. Preference rules and a high ceiling cannot relax these exclusions.

Record only explicit reusable user choices, answers to escalations, and explicit corrections. Never treat silence or continuation as preference evidence. Record in the same turn: when the user answers after `ESCALATE_TO_USER`, run `record --source escalation_answer`; when the user explicitly corrects a `DECIDE`, run `record --source correction` with the delegate's choice as `--prediction` and its confidence (`low`, `medium`, `high`, or `none`) as `--prediction-confidence`. Run these through the `$human-distiller` skill with the `record` action, which resolves `scripts/human_distiller.py` from the shared skill directory. Pass each realistic option as `--option`, the user's choice as `--choice`, and only the reason the user stated as `--reason`. Keep `--context` and every other field generalized: no repository names, file paths, or other identifiers. After recording, run `stats`; when `distillation_review_due` is true, ask the `decision_distiller` subagent for a candidate rule, show its diff to the user, and activate it only after explicit approval. Keep all personal state under `~/.human-distiller/` and never copy it into a project repository.
